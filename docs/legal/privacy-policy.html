CoffeeVision（以下「本アプリ」）
制定日: 2026年7月21日 / 最終更新日: 2026年7月21日

[開発者名]（以下「当方」）は、本アプリにおけるユーザーの個人情報および利用データの取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 収集する情報と利用目的

本アプリは、機能の提供に必要な範囲で以下の情報を取り扱います。

情報取得利用目的備考
位置情報（おおよそ / 正確） アプリ利用中のみ 周辺カフェの検索、地図上での現在地表示 アプリ使用中（when-in-use）のみ取得し、バックグラウンドでの常時取得は行いません。座標はカフェ検索のため Google Places API に送信されます。
写真 ユーザーが添付したとき コーヒー記録への添付・表示 端末内にのみ保存し、外部サーバーへは送信しません。
コーヒー記録（評価 / テイスティング / メモ / タグ / カフェ情報） ユーザーが作成したとき クラウド同期・バックアップ、（同意時のみ）サービス改善のための分析 Firebase Firestore に保存し、匿名のユーザー ID に紐付きます。分析への利用は、初回オンボーディングまたは設定画面の同意（既定は無効）に同意した場合のみ行います。
匿名ユーザー ID 自動 データ同期のためのアカウント識別 Firebase 匿名認証により発行される識別子です。
メールアドレス 任意（Apple でサインインした場合のみ） アカウントの引き継ぎ・アップグレード 「Apple でサインイン」でアカウントを連携した場合に Firebase Authentication が保持します。Apple の「メールを非公開」を選択できます。
診断情報（クラッシュ / パフォーマンス） 常時 アプリの安定性・技術的品質の改善 Firebase Crashlytics / Performance。広告用識別子（IDFA）は使用しません。
使用状況データ（画面遷移等） 同意時のみ サービス改善のための分析 Firebase Analytics。上記のデータ利用同意が有効な場合のみ収集し、IDFA・クロスアプリ追跡は行いません。
広告識別子（IDFA）・広告データ トラッキング許諾時のみ 広告の配信・measurement Google AdMob による広告を表示します。App Tracking Transparency で許諾した場合のみパーソナライズ広告に IDFA を利用し、許諾しない場合は非パーソナライズ広告（IDFA 不使用）を配信します。

2. 第三者サービス

本アプリは以下の第三者サービスを利用し、上表の目的の範囲でデータを送信します。各社のプライバシーポリシーが適用されます。

  • Google（Firebase Authentication / Firestore / Crashlytics / Performance / Analytics、Google Places API、Google AdMob）
  • Apple（「Apple でサインイン」を利用した場合の認証）

本アプリの分析タブの AI 機能（傾向の要約・対話・好みの分析）は、Apple のオンデバイス処理（Foundation Models）で動作し、記録データを外部サーバーへ送信しません。

3. データの保存場所と保持期間

  • コーヒー記録等のデータは Firebase（Google）のサーバー（アジア地域）に保存されます。
  • データはアカウントが存続する限り保持され、アカウント削除により削除されます（下記 4 参照）。
  • 写真は端末内にのみ保存され、アプリの削除または個別削除により消去されます。

4. ユーザーの権利と選択

  • アカウントの削除: 設定画面からアカウントを削除できます。削除時にはクラウド上の記録データも削除されます。「Apple でサインイン」連携アカウントの削除時には、Apple 連携トークンの失効（revoke）を行います。
  • データのエクスポート: 記録データを JSON 形式で書き出せます。
  • 分析への同意の撤回: 設定画面のデータ利用同意トグルをいつでも変更できます。無効にすると使用状況データの収集は停止します。
  • 広告トラッキングの選択: iOS の「設定 > プライバシーとセキュリティ > トラッキング」および初回の許諾ダイアログで選択・変更できます。

5. 子どものプライバシー

本アプリは 13 歳未満の子どもを主たる対象としておらず、13 歳未満の子どもから意図的に個人情報を収集することはありません。

※ App Store の年齢レーティング設定と整合させてください。対象年齢の方針が異なる場合はこの記述を調整してください。

6. 準拠法・配信地域

本アプリは日本国内での配信を対象とし、本ポリシーは日本法に準拠します。

7. 本ポリシーの改定

当方は、必要に応じて本ポリシーを改定することがあります。重要な変更を行う場合は、本アプリまたは本ページ上で告知します。
